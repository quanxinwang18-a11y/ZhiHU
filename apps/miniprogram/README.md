# 职乎微信小程序

这是从现有 Web 原型向原生微信小程序推进的第一个纵向切片，目标是先验证：

```text
游客提问
  → 轻触事件视界，问题被“投入”
  → 动态选择三个互补视角
  → 三张判断卡在后台并行凝结
  → 用户逐张显影身份并进入全屏判词
  → 可选行动判断 / 沟通话术
  → 结果保存在小程序本地
```

当前不是正式发布版本。默认运行完全位于小程序内的可控 Mock，不需要登录、数据库或模型 Key。

## 当前交互模型

小程序没有照搬 Web 的 Three.js、音乐和桌面全屏，而是保留了 Web 体验中真正承载产品意义的交互节奏：

1. **投入**：提交不是普通表单跳转。轻触事件视界后，问题先经过 720ms 的收束动画，再开始寻找视角。
2. **凝结**：模型生成进度与用户阅读进度彼此独立。流式回答在后台到达，牌面在完成前始终保持封印。
3. **显影**：第一次轻触已完成卡牌，只翻转卡牌并展示身份、功能槽位和选择原因，不立刻铺开长回答。
4. **阅读**：再次轻触进入独立的全屏判词空间；已显影卡牌可通过按钮或横向手势切换。
5. **收束**：只有三张可用卡全部显影后，才出现“形成行动判断”和“组织沟通话术”。它们是可选出口，不是首页任务。

关键交互使用短震动确认，模拟器中可能没有触感；真机仍需在真实 AppID 下复验。

## 打开方式

1. 从[微信官方页面](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)安装微信开发者工具。
2. 在微信开发者工具中选择“导入项目”。
3. 项目目录选择仓库内的 `apps/miniprogram`。
4. 仅做本地模拟器开发时，AppID 可暂时使用配置中的 `touristappid`。
5. 编译后可直接使用示例问题体验。

`touristappid` 只能用于本地模拟器验证。点击“预览”生成真机二维码时，开发者工具会返回“此 AppID 不存在”；真机预览和真机调试必须换成真实小程序 AppID，并由该小程序的开发者账号登录工具。

本机已在 2026-07-31 使用微信开发者工具 RC `2.02.2607271`、基础库 `3.17.0` 完成以下验证：

- `apps/miniprogram` 导入和普通编译成功，工具“问题”面板为 0；
- iPhone 12/13 Pro 模拟器中的首页、示例问题、事件视界投入和三卡并行凝结正常；
- 封印卡横向牌轨、第一次点击翻转、身份聚焦层、第二次点击进入全屏判词均正常；
- 已显影卡牌的阅读位置和前后切换状态正常，三卡全部显影后才显示可选出口；
- “形成行动判断”出口正常生成结果；
- 历史页能够读取刚完成的问题和三张卡，并在重启开发者工具后保留；
- 预览命令到达官方 AppID 校验阶段，并确认当前唯一阻塞是 `touristappid`。

游客模式控制台中的 `webapi_getwxaasyncsecinfo:fail` 和 `wx.operateWXData` 受限提示来自开发者工具的游客模式，不是当前业务代码的编译错误。换用真实 AppID 后仍需重新检查控制台和真机行为。

开发者工具会生成只属于本机的 `project.private.config.json`；仓库已忽略该文件，团队共享配置继续维护在 `project.config.json`。

TypeScript 类型检查：

```bash
pnpm typecheck:miniprogram
```

## 联调无状态 API

先在仓库根目录启动 Next.js：

```bash
pnpm dev
```

再将 `config/runtime.ts` 中的 `apiBaseUrl` 临时改为：

```ts
apiBaseUrl: "http://127.0.0.1:3000",
```

开发者工具项目配置已关闭本地联调阶段的域名校验。真机联调不能使用
`127.0.0.1`，需要换成手机可访问的 HTTPS 测试域名。

API 使用 NDJSON 分块事件：

- `plan`
- `card.delta`
- `card.done`
- `card.failed`
- `run.done`

客户端包含跨分块 UTF-8 解码，不能假设一次 `onChunkReceived` 正好对应一行 JSON。

## 当前隐私边界

- 本地 Mock 不会发送问题。
- API 联调模式会在生成期间把问题发送给本项目后端。
- v2 接口不读取登录态，不向 SQLite 写问题或回答，也不会记录问题正文。
- 问题和完整回答最多保存 20 条在微信本地存储。
- 当前本地历史尚未加密；它解决的是服务端开发者看不到正文，不防护已控制用户设备的攻击者。
- 接入真实模型后，模型供应商会在推理期间处理问题明文，产品说明必须明确披露。
