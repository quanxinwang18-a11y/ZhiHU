# 职乎前端效果截图（历史基线）

本目录保存的是早期黑曜金版本的 PC 桌面端截图，用于回看基础交互和视觉演进，不是当前代码的完整功能截图，也不应作为最新 UI 的逐像素验收基线。

截图拍摄时已覆盖登录、随机数量选择、四卡生成、阅读、追问和历史管理，但拍摄早于以下当前功能：

- 12 个内置视角全部就位
- “引力抽取 / 指定显影”双模式
- 自定义神明、显像、引力场与神格快照
- 五套按卡牌包持久化的视觉光谱
- 历史回声
- 单卡碎裂与卡轨收拢
- “蒸馏”占位入口

因此，截图中旧名称、旧控制面板、旧文案或单一黑曜金色彩不代表当前实现。当前产品能力请以仓库根目录 `README.md`、`outputs/职乎-产品需求与交互设计.md` 和实际运行页面为准。
