# 黑曜金视觉审计（历史基线）

本目录记录早期黑曜金视觉系统的四个关键页面状态。它仍可用于检查“深色宇宙、骨白正文、低饱和金色强调、单行卡轨”的视觉来源，但不再覆盖当前代码的全部样式与交互。

## 当时的参数基线

- 环境黑：`#0a0908`
- 骨白：`#e9e2d6`
- 哑光金：`#c8b38e`
- 全局胶片颗粒：`4%`
- 顾问正文：`15px / 27px`
- 卡牌：默认四张、单行排列
- 卡牌出现后背景：`opacity(.66) blur(1.2px) saturate(.58) contrast(.72)`

## 页面状态

| 文件 | 当时展示的状态 |
| --- | --- |
| `after-login.png` | 登录与注册材质 |
| `after-home.png` | 问题输入与黑洞光环 |
| `after-cards.png` | 四张卡牌的单行景深 |
| `after-manuscript.png` | 顾问手稿、多轮追问与个人决定 |

## 与当前实现的差异

当前代码已从单一黑曜金扩展为五套持久化光谱：

- 黑曜神谕
- 月蚀银蓝
- 紫微星云
- 赤焰灾星
- 翡翠深空

同时增加了指定显影、自定义神明、历史回声、卡牌翻转揭示、单卡碎裂和卡轨压缩等状态。本目录没有这些状态的截图。

早期文档记录的“17 项单元测试、2 项端到端测试”也已失效。当前代码基线为 36 个 Vitest 测试和 3 条 Playwright Chromium 主链路；最新测试状态以根目录 `README.md` 为准。

图片扩展名为 `.png`，但当前文件内容实际采用 JPEG 编码。后续若更新视觉审计，建议：

1. 以当前代码重新拍摄至少五套光谱中的代表状态。
2. 补充随机抽取、指定显影、造神、历史回声和单卡碎裂。
3. 使用与文件扩展名一致的真实 PNG 或直接改为 `.jpg`。
4. 记录浏览器版本、视口、提交版本和是否启用降低动态效果。
