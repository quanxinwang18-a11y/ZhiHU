# 黑白金视觉系统验收

本目录记录 1920 × 1080 桌面视口下的四个关键状态，用于核对《求知台》“黑曜石、骨白、哑光金”的新构成主义视觉语言。

## 参数基线

- 环境黑：`#0a0908`
- 骨白：`#e9e2d6`
- 哑光金：`#c8b38e`
- 全局胶片颗粒：`4%`
- 顾问正文：`15px / 27px`
- 卡牌：默认四张、单行排列
- 卡牌出现后黑洞景深：`opacity(.66) blur(1.2px) saturate(.58) contrast(.72)`

## 页面状态

- `after-login.png`：登录与注册材质
- `after-home.png`：问题输入与黑洞光环
- `after-cards.png`：四张顾问卡牌的单行景深
- `after-manuscript.png`：顾问手稿、多轮追问与用户决策区

自动化验证结果：ESLint、17 项单元测试、2 项端到端测试与生产构建全部通过；浏览器控制台错误为 0。
